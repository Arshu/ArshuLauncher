Try it on Hacker News

The quickest way to see what this does. One command downloads the launcher and a read-only Hacker News skill, and opens a terminal and a browser side by side. You click around news.ycombinator.com; the assistant adds topic tabs, shows fast risers and high-karma submitters, collapses near-duplicate comments and can summarise a thread. It never posts, replies or votes, and the AI cost of the session stays on screen.

Needs your assistant (Claude Code shown) installed and signed in, Chrome or Edge, and Node.js 20+. Not sure? Start with the install steps. The command installs nothing else, and works in a folder of its own: Documents/AIWork.

irm https://raw.githubusercontent.com/Arshu/ArshuLauncher/main/hackernews.ps1 | iex
curl -fsSL https://raw.githubusercontent.com/Arshu/ArshuLauncher/main/hackernews.sh | sh
curl -fsSL https://raw.githubusercontent.com/Arshu/ArshuLauncher/main/hackernews.sh | sh

Read the script first if you like: hackernews.sh, hackernews.ps1. For Codex or pi, pass codex or pi (Windows: set $env:HN_HARNESS first). The cost line needs .NET 10; without it the page says the cost is unavailable.

Then say, for example:

Get started

For developers and QA people: you paste a few commands into a terminal, once. Tested on Windows 11, macOS and Ubuntu; Windows 10 has not been tested. Pick your computer:

One line

With your assistant installed and signed in, Chrome or Edge, and Node.js 20+, paste this. It makes a work folder, downloads the launcher and starts it. Missing something? --doctor names it and the fix.

mkdir $HOME\Documents\AIWork -Force; cd $HOME\Documents\AIWork; iwr https://github.com/Arshu/ArshuLauncher/releases/latest/download/runJointLauncher-win-x64.exe -OutFile runJointLauncher.exe; .\runJointLauncher.exe --harness claude
mkdir -p ~/Documents/AIWork && cd ~/Documents/AIWork && curl -fsSL https://github.com/Arshu/ArshuLauncher/releases/latest/download/runJointLauncher-osx-$(uname -m | sed s/x86_64/x64/) -o runJointLauncher && chmod +x runJointLauncher && ./runJointLauncher --harness claude
mkdir -p ~/Documents/AIWork && cd ~/Documents/AIWork && curl -fsSL https://github.com/Arshu/ArshuLauncher/releases/latest/download/runJointLauncher-linux-$(uname -m | sed 's/x86_64/x64/;s/aarch64/arm64/') -o runJointLauncher && chmod +x runJointLauncher && ./runJointLauncher --harness claude

Use --harness codex or --harness pi for those assistants. The launcher itself installs nothing.

First time? Install the prerequisites step by step

Open a terminal

A terminal is a window where you type commands. Type (or paste) a command, then press Enter.

Press the Windows key, type Terminal and press Enter. Paste with Ctrl+V.

Press ⌘ Command + Space, type Terminal and press Enter. Paste with ⌘+V.

Press Ctrl + Alt + T, or open Terminal from your apps. Paste with Ctrl+Shift+V.

Install what you need (once)

Run each line. After installing, close the terminal and open a new one so it finds the new programs.

Download and start

Make a folder for your work, download the launcher into it, and start it:

curl -fsSL https://github.com/Arshu/ArshuLauncher/releases/latest/download/runJointLauncher-osx-$(uname -m | sed s/x86_64/x64/) -o runJointLauncher && chmod +x runJointLauncher

How it is different

The first question developers ask, answered in a line each.

Playwright MCP, Browser Use

They give an assistant a browser to drive on its own, usually out of sight. Arshu Launcher is the pairing: terminal and a visible browser side by side, a shared window you can click in, and a review workflow. It uses Playwright underneath.

Claude in Chrome

Works inside your everyday Chrome and its sign-ins. Arshu Launcher starts a fresh, empty browser profile each session, and also works with Codex and pi.

What it does

Everything explained in plain words in FEATURE.md.

Arranged for you

Terminal and browser fill your screen side by side or stacked, in the sizes you choose, and it remembers them.

You see every step

The assistant opens pages, clicks and types in the shared browser in front of you. You can click too.

Nothing passes silently

Each action is checked: a button that does nothing, a page error or a pop-up is reported, not skipped.

Review a site together

Walk through a flow step by step, collect what's wrong, fix it (when you agree) and run it again.

Helps you set up

A built-in check lists what's missing with the exact fix, and the assistant can install it, asking first.

Private and simple

A fresh browser profile each time, a control port only your computer can reach, and one readable file.

Questions

More answers, and fixes for common problems, in USAGE.md.

Who is it for?

Developers and QA people who want to watch an AI assistant test or review a website. You paste a few commands into a terminal once, then you talk to the assistant in plain words.

Is it free?

The launcher is free and open source under the MIT license. It works with the Claude Code, Codex or pi you already have; that assistant may need its own account or subscription, which the launcher does not add to.

Can the assistant see my passwords or browsing history?

No. The shared browser starts with a fresh, empty profile every time, separate from your normal browser.

Will it install things without asking?

No. The launcher installs nothing by itself. When something is missing, the assistant explains it and asks before each install.

How do I stop a session?

Close the two windows. Nothing keeps running in the background.

Which computers does it work on?

Tested on Windows 11, macOS and Ubuntu Linux. Windows 10 has not been tested, so it is unknown whether it works.

Where do I ask a question or report a problem?

In GitHub Issues. Run ./runJointLauncher --doctor first and paste what it prints.

Something didn't work. What now?

Run ./runJointLauncher --doctor. It names each problem and how to fix it. Most problems come from a terminal opened before an install: open a new one.
